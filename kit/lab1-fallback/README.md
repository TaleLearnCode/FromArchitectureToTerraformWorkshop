# Lab 1 fallback

This folder holds two saved AI outputs for Lab 1, for use when your AI assistant is slow or unavailable:

- `run1\`: Terraform an AI assistant wrote from the infrastructure architecture guide
- `run2\`: Terraform from the same prompt, same model, in a fresh chat

Start Lab 1 at step 5 (compare the two runs) using these folders in place of `lab1\run1` and `lab1\run2`.

The two runs are added by the facilitator before the workshop. If they are missing, partner with a neighbor who has an assistant working.
